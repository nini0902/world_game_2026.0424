# Vision

## Problem Statement

本專案要解決的是：提供一個門檻低、節奏輕、可快速進入狀態的世界觀小故事遊戲體驗。
主要使用者是第一次接觸此類型遊戲的新手玩家，以及偏好短時段遊玩的輕度玩家。
現有方案常見問題是內容過重或系統複雜，讓玩家在早期就流失。

## Core Idea

做一款「簡單的世界觀小故事遊戲」：用短篇劇情與清楚的過關節奏，
讓玩家能快速上手、逐步投入，並在小步推進中感受到成就感。

## Current State

目前為初版階段，核心方向已確立，重點放在先完成可玩的最小版本，
再逐步增加內容與挑戰深度。

## Architecture

目前採小步交付、可追溯變更導向：
- 需求先定義再實作
- 以可驗證、可除錯為品質門檻
- 先確保主流程可玩，再擴充內容

詳細技術與設計決策後續補到 knowledge/design/。

## Roadmap

### Phase 1: 初心者

- [ ] Complete

Delivers:
- 建立最小可玩流程（開始 -> 劇情片段 -> 基礎挑戰 -> 結果）
- 完成新手可理解的操作與回饋節奏

Prerequisites:
- none

**Success criteria:**
- [ ] 新玩家可在短時間內完成第一輪流程
- [ ] 主流程可穩定跑完且可重現主要行為
- [ ] 至少一段世界觀小故事可完整體驗

### Phase 2: 過關斬將

- [ ] Complete

Delivers:
- 加入進階關卡與連續挑戰節奏
- 擴充故事節點與過關回饋，形成持續推進感

Prerequisites:
- Phase 1

**Success criteria:**
- [ ] 玩家可連續完成多段挑戰並獲得清楚進度回饋
- [ ] 失敗與重試流程清楚，不會卡在無法前進狀態
- [ ] 劇情與挑戰能形成一致的推進動機
